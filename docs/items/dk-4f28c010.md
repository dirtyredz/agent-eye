# Split CaptureError into camera failures and session-wide failures under service/

v1.3.0 Sol sign-off 2026-10-26 (PASS with this P1). android/app/src/main/java/local/agenteye/camera/CaptureError.kt:8 holds session-start, LAN-bind and Wi-Fi failures that are not camera concerns, so CaptureSnapshot and the UI depend on camera/ for a session-wide contract. It was placed in camera/ deliberately so CameraSession need not import service/ (moving it as-is would add a camera -> service cycle).

Direction: camera/ keeps only camera failures (camera_unavailable, capture_failed); a session-wide failure type under service/ (adds wifi_unavailable, bind_failed, session_start_failed) wraps them at the CaptureService boundary. /status wire codes must not change (CaptureErrorTest pins them).
